# Roadmap

## 1. Vertical Slice

Create one playable defense loop with hero selection, one outpost, basic enemies, simple buildables, wave progression, and a boss encounter.

## 2. Team Survival

Improve co-op flow with readiness, revives, shared objectives, HUD updates, and clearer win/loss states.

## 3. Hero Classes

Expand Vanguard, Ranger, Engineer, and Medic abilities while keeping ability effects server-authoritative.

## 4. Buildables

Add placement rules, repair flow, server-owned turret targeting, trap triggers, and upgrade hooks.

## 5. Progression

Introduce persistent hero and base upgrades, data validation, reward balancing, and safe save/load behavior.

## 6. Companions

Explore companion systems after the core survival loop is stable. Do not add pets before this phase.

## 7. Monetization

Evaluate ethical monetization only after the game loop, progression, and retention are proven. Do not add monetization before this phase.
